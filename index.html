Mock fibre routes: 3 web map options

All pages load the same sites.geojson and routes.geojson, exported from PostGIS.

  • Google Maps JavaScript API: needs an API key (set at the top of google.html).
  • Leaflet + OpenStreetMap raster tiles: no key.
  • MapLibre GL JS + OpenFreeMap vector: no key, with a toggle to OSM raster.
